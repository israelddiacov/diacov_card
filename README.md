## 📌 Sobre o Projeto

Este projeto é uma **experiência digital imersiva e responsiva em tela cheia (100vw x 100vh)** ambientada em uma estética retrô vibrante dos **anos 60 (Mid-Century Modern)**. Inspirado nos conceitos visuais de design espacial e storytelling interativo (estilo *igloo.inc*), o cartão combina entretenimento visual com apresentação de alto valor comercial.

O cartão roda **100% no navegador (Client-side / Vanilla JS)** sem dependências pesadas de servidores, sendo ideal para hospedagem gratuita e ultrarrápida no **GitHub Pages**.

## 🩺 Soluções para a Área da Saúde (HealthTech & Regulação)

Desenvolvimento de ecossistemas médicos de alta complexidade técnica e regulatória:

* **Conformidade Regulatória com a ANS:** Portais e operadoras de planos de saúde estruturados de acordo com as diretrizes e normas da **ANS (Agência Nacional de Saúde Suplementar)**, com suporte aos padrões **TISS** (Troca de Informações na Saúde Suplementar) e **TUSS** (Terminologia Unificada da Saúde Suplementar).
* **Integração com o CNES (Ministério da Saúde):** Conexão oficial via webservices e APIs REST com o **Cadastro Nacional de Estabelecimentos de Saúde** para validação cadastral e credenciamento.
* **Tabelas Médicas Oficiais:** Faturamento e auditoria com aplicação rigorosa das tabelas **CBHPM**, **TUSS**, **SIMPRO** e **Brasíndice**.
* **OCR & Automação de Guias Médicas:** Reconhecimento óptico de caracteres para processamento automático de guias de consulta, SADT e internação, com conciliação financeira automatizada.
* **Telemedicina em Tempo Real:** Salas de vídeo consulta seguras com protocolo **WebRTC** ponta a ponta, agendamento e integração com prontuário.

## 📱 Recursos Mobile & PWA

* **Salvar Contato (.vCard):** Download de arquivo `.vcf` pronto para importar com 1 toque para a agenda do celular.
* **QR Code Dinâmico:** Gerado nativamente via Canvas no navegador para leitura rápida por câmeras.
* **Compartilhamento Nativo:** Integração com a Web Share API do celular.
* **Formulário de Orçamento WhatsApp:** Coleta dados do cliente e redireciona para o WhatsApp com mensagem estruturada.
* **Painel Privativo de Contatos:** Armazenamento seguro de solicitações no navegador com opção de exportação em planilha `.csv`.
* **Suporte Offline:** Service Worker (`sw.js`) configurado com cache local para carregamento instantâneo.

## 🚀 Como Executar Localmente

Como o projeto é 100% estático, não requer instalação de pacotes ou compiladores:

1. Clone o repositório:
   ```bash
   git clone https://github.com/israelddiacov/diacov_card.git
   cd diacov_card
   ```
2. Abra o arquivo `index.html` em qualquer navegador moderno (Chrome, Edge, Firefox, Safari):
   ```bash
   # No Windows (PowerShell):
   start index.html
   ```
